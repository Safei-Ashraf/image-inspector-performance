Image Inspector

Click any image on a page — or audit the whole page at once — and find out which images can safely be served at a smaller verified CDN width, with measured byte savings and a ready-made fix prompt for your coding agent. Fastly-ready out of the box, configurable for any CDN that resizes via URL parameter.

What it does

Three ways to catch oversized images

The extension compares each rendered image against the widths your Fastly CDN actually honors, at the DPR you actually target — and tells you the exact safe width to request instead.

🖱

Inspect one image

Click the toolbar icon, then click any image. Get an instant Keep as is or Use Npx verdict with the full sizing math.

📊

Audit the full page

One click scrolls the page to trigger lazy images, scans every <img> (including shadow DOM) and CSS background, and ranks every source by savings.

🤖

Hand off to an agent

Generate a portable Markdown task with measured totals, exact width changes, and safety constraints — ready to paste into any coding agent.

Any CDN

Not just Fastly

🌐

1 · Add your hosts

Options → CDN measurement → add your CDN hostnames. Chrome asks for a one-time permission; subdomains match automatically.

🔧

2 · Set the parameter

Options → CDN width parameter → the query key your CDN resizes with (width, w, …). Used to detect and rewrite requested widths.

📏

3 · Verify your widths

Options → Verified CDN widths → paste your probed list, or fetch it from a URL. Recommendations only ever use values in this list.

Probing tip: request image.png?width=480 and check the delivered width of the response — keep the values your CDN honors exactly, drop the ones it rounds or clamps. Measurement depth: Fastly hosts get full fastly-io-info metadata (dimensions + bytes); other HTTPS hosts still get content-length byte measurements, and anything unfetchable is clearly badged Estimated.

Install

Six steps, two minutes

The extension runs as a local, unpacked extension. No store, no account, no cost — just load the folder once and Chrome keeps it installed.

Get the code

Either download and unzip the latest ZIP, or clone it: git clone https://github.com/Safei-Ashraf/image-inspector-performance.git. Cloning makes future updates a one-liner.

Open the extensions page

Type chrome://extensions in the address bar and press Enter.

Enable Developer mode

Flip the Developer mode toggle in the top-right corner.

Load unpacked

Click Load unpacked and select the image-inspector-performance folder (the one containing manifest.json).

Pin it

Click the puzzle-piece icon in the toolbar and pin Image Inspector so it's always one click away.

Add your CDN host

Open the extension's Options, add your CDN hostname(s) under CDN measurement, and save — Chrome will ask for a one-time permission. Nothing is measured until you do this.

Use

Read an audit at a glance

Open any page, click the extension icon, then click Analyze full page. Every image gets a colored outline and the dashboard ranks sources from highest to lowest opportunity.

Green — keep as is. Already optimal or source-limited.
Yellow — low savings. Small win; fix when convenient.
Orange — medium savings. Worth reviewing.
Red — high savings. Must fix; biggest byte wins.
Gray — not measurable. Hidden or never loaded; scroll it into view and rerun.

Dashboard

What's in the results panel

The completed audit stays open while you work the page.

  • Ranked results with exact width changes (e.g. 2400px → 480px), saved bytes and percent, and the DPR that stays covered.
  • Payload totals — current vs. optimized unique image bytes, per-visit savings, and a projection (labeled as an upper bound unless you set a realized-traffic factor).
  • Filters by High / Medium / Low / Keep / N-A severity.
  • Locate — click any row to scroll its image into view, pulse its border, and show the safe step.
  • Hover & pin — hover any outlined image for a quick verdict; click to pin its full analysis above the results.
  • srcset warnings — responsive images are flagged as sampled at the current viewport only.
  • Implementation benchmark — whether each row should add, replace, or keep its width parameter, with a shared setImageWidth helper.
  • Generate task prompt — preview, copy, or download a Markdown handoff for a coding agent.
  • Draggable & minimizable — drag by the header, resize from the corner, minimize without losing the audit.

FAQ

Troubleshooting

The common bumps, solved.

The toolbar icon shows a red "!" badge

The page couldn't be injected — Chrome Web Store pages, chrome:// pages, and PDFs are off-limits to all extensions. Try a regular page.

Images show as gray / "Not measurable"

They were hidden or still loading during the audit. The audit already auto-scrolls and waits, but some carousels and late-mounted widgets need a manual scroll — then press Run again.

A saving says "Estimated" instead of "Measured"

The optimized variant couldn't be fetched from the CDN (non-CDN host, or a blocked request), so the byte figure is a pixel-area estimate. Treat it as indicative, not exact.

Nothing is being measured at all

No CDN hostname is configured yet. Open Options, add your CDN host(s) under CDN measurement, and save — Chrome requires a one-time permission grant per host.

How do I remove it?

Go to chrome://extensions and click Remove on the Image Inspector card. The folder can then be deleted.
